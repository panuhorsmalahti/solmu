Boxer

Choose project permissions on Linux and macOS, add read-only references or writable result folders, and reuse inspectable policies. Check that your OS can apply them before launching. Launch the backend inside Boxer to protect its tools. Profiles also launch installed Codex and Claude Code CLIs with separate logins. On Linux, add private processes, resource limits, and explicit network routes for your provider and backend. Network access stays allowed by default; choose offline execution for standalone commands.

boxer --profile solmu --cwd /path/to/project -- solmu-backend

Stop your regular backend first, then connect any Solmu client using its default settings. Running boxer alone opens the Solmu terminal client. Permissions are unrestricted by default; native Windows currently provides process-tree containment.

Choose your sandbox permissions ↗

Muxer

Several threads at once? Group real terminal tabs into project spaces. Keep interactive shells and project commands beside Solmu; stopped command output remains readable, and saved commands wait for an explicit restart. Name your spaces, tabs, and panes; find them with instant search or navigate with the keyboard and mouse. Split panes right or down, drag dividers to resize, and zoom into one conversation. Detach while replies keep running, then reattach to your local session. Named sessions and multiple terminal clients keep your projects organized. Layouts and Solmu conversations return after a server restart. Customize colors and shortcuts in Settings; changes apply automatically. Prefer a window? Run muxer-gui to switch spaces, inspect pane screens, and send terminal input in a native desktop app. Local automation commands manage layouts, inspect sessions, send terminal input, and read pane screens. Follow live events or wait for a pane state or matching output. Queue prompts directly to Solmu, wait for a specific reply, and stop pending work while preserving terminal drafts. Attach directly to one pane, or stream its screen to scripts with multiple observers and one controller.

MAKE YOURSELF AT HOME

Start with a single command.

Linux & macOS

curl -fsSL https://raw.githubusercontent.com/panuhorsmalahti/solmu/main/scripts/install-bundle.sh | sh

Windows PowerShell

irm https://raw.githubusercontent.com/panuhorsmalahti/solmu/main/scripts/install-bundle.ps1 | iex

The optional bundle installs the backend, terminal and desktop clients, Boxer, Muxer, and Muxer GUI from the latest production release and starts the backend in the background. Build the native Android app in Android Studio. The latest installers register installed modules for daily updates; rerun each installer once for existing installs. Run a module installer again to update it immediately. Add your provider key in ~/.solmu/.env and restart the background backend. Run solmu, solmu-desktop, muxer, or muxer-gui; open http://127.0.0.1:3000 for the web client. Install or update individual modules if you only need one. Bundle setup includes service management.
