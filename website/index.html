ROOM TO EXPLORE

Your workspace, your way.

Boxer

Launch Solmu or another agent with native OS controls. On Linux, opt into an isolated workspace with private processes and resource limits. Network access stays allowed.

boxer --cwd /path/to/project -- solmu-cli

Running boxer alone opens the Solmu terminal client. Permissions are unrestricted by default.

Choose your sandbox permissions ↗

Docker

Run your backend in a container and keep conversations in a persistent volume. Connect from any Solmu client.

Run with Docker ↗

Muxer

Several threads at once? Real terminal sessions, workspace switching, split views, and live activity states in one window.

muxer
Solmu Muxer ↗
MAKE YOURSELF AT HOME

Start with a single command.

Linux & macOS

curl -fsSL https://raw.githubusercontent.com/panuhorsmalahti/solmu/main/scripts/install.sh | sh

Windows PowerShell

irm https://raw.githubusercontent.com/panuhorsmalahti/solmu/main/scripts/install.ps1 | iex

Installs the backend, clients, Boxer, and Muxer from the latest production release. Before the first release, build from source. Then add your provider key and start the backend.
