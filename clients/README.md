# Solmu clients

The clients connect to the same backend:

Screenshots: [CLI](../docs/screenshots/cli.png) ·
[Desktop](../docs/screenshots/desktop.png) · [Web](../docs/screenshots/web.png).
Android screenshot: [native app](../docs/screenshots/android.png).

- [CLI](cli/README.md): a Rust terminal interface.
- [Desktop](desktop/README.md): a native Rust app using Iced.
- [Android](android/README.md): a native Kotlin and Jetpack Compose app.
- [Web](web/README.md): React with shadcn/ui.

Each supports saved conversations, streamed replies, automatic thread names,
live updates, and response cancellation. See [the client guide](../docs/clients.md).
