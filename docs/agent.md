# Solmu agent

Solmu starts each conversation request with the system prompt:

> You are Solmu, an autonomous agent.

The full saved conversation follows the prompt. Current capabilities are
conversation management and streamed model replies. More agent instructions
and capabilities will be added as Solmu develops.

You can stop a reply while waiting for it. The user message remains saved;
an interrupted assistant reply is discarded. Automatic title generation can
still finish after stopping a reply.
