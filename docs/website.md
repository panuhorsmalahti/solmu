# Solmu website

The one-page Solmu introduction is hosted on
[GitHub Pages](https://panuhorsmalahti.github.io/solmu/).
It introduces all clients, streaming replies, saved conversations, automatic
titles, provider choice, and running your own backend.

Preview with `npm run dev:website` and open `http://127.0.0.1:4174`.
Changes under `website/` are deployed from `main` by the Pages workflow.
The workflow can also be run manually. GitHub Pages must use **GitHub Actions**
as its publishing source in repository settings.

The website is an introduction, not the conversation client. To use Solmu,
follow its installation link and run a backend with a terminal, desktop, or
web client. The site does not collect conversations or provider credentials.
